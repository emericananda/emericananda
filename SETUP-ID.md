# Portofolio GitHub Nanda

Paket berisi README profil berbahasa Inggris dan banner lokal. Ini belum diunggah ke akun GitHub.

## Pasang

1. Buka akun GitHub kamu.
2. Buat repository publik dengan nama persis username GitHub kamu. Contoh: jika username `nama-kamu`, repository juga `nama-kamu`.
3. Unggah `README.md` dan folder `assets` dari paket ini ke root repository. Jika sudah ada profile README, gabungkan atau ganti setelah menyimpan salinan lama.
4. Jangan unggah SETUP-ID.md ke profil publik; ini catatan pribadi pemasangan.
5. Lihat profil GitHub untuk mengecek banner, tabel, dan tautannya.
