# Update profil GitHub emericananda

Versi ini mengutamakan olahraga. Bagian IT diringkas di bawah. Empat kolaborasi brand ditambahkan sesuai konfirmasi Nanda: Pirelli, Castelli, Spectrum Optics, dan Cervélo.

## Upload ke repository yang sudah ada

1. Ekstrak ZIP ini.
2. Buka https://github.com/emericananda/emericananda dan login dengan akun pribadi emericananda.
3. Klik Add file → Upload files.
4. Tarik README.md dan folder assets ke area upload, di root repository. Jangan upload ZIP atau folder pembungkusnya.
5. GitHub akan mengganti README.md dan assets/header.png dengan versi baru, lalu menambahkan assets/brands.png.
6. Klik Commit changes. Jika menggunakan branch lain, gabungkan ke default branch agar profil terbarui.
7. Buka https://github.com/emericananda untuk melihat hasilnya.

File SETUP-ID.md dan LOGO-SOURCES.md hanya catatan pribadi; tidak perlu diupload. File ini belum dipasang langsung ke GitHub.
